# MyriSaying

`MyriSaying.py` is the only Python script. Run it **inside Autodesk Fusion**:

1. Open **Utilities → Scripts and Add-Ins → Scripts**.
2. Add this `MyriSaying` folder, select **MyriSaying**, and click **Run**.
3. Save the new design in Fusion. Export a mesh manually when needed.

Keep `MyriSaying.manifest` beside the script so Fusion can discover it. No package installation, external font files, assets folder, or exports folder is required. The exact cursive geometry is embedded in the script, and all five colored mesh bodies are created directly in memory using Autodesk's [MeshBodies.addByTriangleMeshData API](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_MeshBodies_addByTriangleMeshData.htm). These remain mesh bodies, not sketch/extrusion features.

Each Fusion run appends timestamped inputs, geometry checks, creation stages, and errors to **`MyriSaying.log`** beside the script. The log is the only file the script writes. Existing preview images and the top-level 3MF are retained as reference files; they are not required or regenerated by the script.

The design is unchanged:

- **200 × 100 mm face, 3 mm panel**, black background.
- **Brown twisted-rope border**, 6 mm wide, projecting up to approximately 2.5 mm beyond the face.
- **White Snell Roundhand Bold lettering**, raised 1.2 mm, with a larger saying and smaller name/date.
- **10° backward lean** and two black triangular supports with flat bottoms; each is 8 mm wide with 40 mm rearward projection.

> The super power that you'll
> never lose is being the
> best daddy ever.
>
> Myriam Howard
> March 19, 2023

Thickness, relief, lean, rope settings, support dimensions, and colors can be changed in the constants near the top of the script. The embedded lettering preserves this specific inscription, font, layout, face dimensions, and border width; those settings must remain matched to the embedded geometry.

Consolidation checks confirmed identical vertex/triangle data, colors, watertightness, volumes, and standing balance for all five parts. The in-memory Fusion creation path still needs verification by running the script in Fusion. A physical print has not been tested.
