# BuildPlans instructions

- Keep each Fusion project in its own folder.
- Use one self-contained Python script per project.
- Do not create Python support files.
- Write a sidecar .log beside the script when it runs.
- Do not create assets, archive, or exports folders.
- Keep mockup.png current when artwork changes.
- Use millimeters for dimensions.
- When asked to run a Fusion script, use:
  http://127.0.0.1:27182/mcp
- Verify generated dimensions and appearance in Fusion.
